# DPDP Compliance Matrix (UPYOG)

| Obligation | UPYOG component |
|------------|-----------------|
| Notice & consent | `NoticeService`, `ConsentService`, MDMS `NoticeTemplate` |
| Principal rights | `RightsService`, data providers, SLA fields |
| Grievance redressal | `GrievanceService`, 90-day SLA |
| Retention / erasure | `RetentionService`, erasure job tables |
| Breach notification | `IncidentService`, `BreachDeadlineScheduler` |
| Accountability | `AccessLogService`, privacy events |
